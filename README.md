# Лабораторная работа №2: Программа с системой защиты
Пример реализации консольной утилиты с триальной версией на C++.

## Описание
Разработана консольная утилита, которая запрашивает ФИО пользователя и сохраняет его в файл. Программа оснащена системой защиты, ограничивающей ее использование по времени и количеству запусков.

## Основные возможности
-   **Запрос ФИО** пользователя.
-   **Сохранение данных** в файл в папке установленной программы (`C:\Program Files\Lab2\list.txt`).
-   **Проверка на дубликаты** ФИО перед записью.
-   **Двойная система лицензирования (триал-версия):**
    -   Ограничение по количеству запусков (`5 запусков`).
    -   Ограничение по времени использования (`3 минуты` с момента первого запуска).
-   **Защита от переустановки:** состояние триала хранится в реестре Windows (`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`) и не удаляется при деинсталляции.
-   **Полный пакет для дистрибуции:** инсталлятор и деинсталлятор, корректно регистрирующие программу в системе.

### Сборка инсталлятора
1.  Установите NSIS.
2.  Откройте файл `install.nsi` в NSIS.
3.  Нажмите "Compile". Готовый `setup-Laba2.exe` будет создан в указанной в скрипте папке.
